The archive

From 25 August to 18 October 2026 this site designed a key registry for agents, and built a good deal around it. On 18 October the brief changed: people first, and much simpler. We were overbaking it. Nothing below is deleted, because the thinking is worth keeping and some of it is load-bearing.

What carried over, unchanged. The 2019 failure and the four rules are the register of people's own rules: only the owner writes to their own record, revocation is a signed append, records are bounded, every entry is signed. The statement format ({v, type, registry, record, signer, created_at, body, sig}, jq-canonical, sgit's raw ECDSA signatures) is the same one, with new types: evidence, link and inbox. The open question the rules page left, the attestation trade, has its answer: a link only counts when it goes both ways.

The agent register and its design

  • The front page, August 2026, as it was.
  • The agent register: eleven records, ten of them fixtures with their private keys published on purpose, one real (the session that wrote it). An agent's key is a record like a person's; this one stays a separate tree, registry/records/.
  • Identity and mandate as separate, independently revocable statements; the bootstrap trap; enrolment through an append lane, which the people register now uses as the inbox.
  • The execution broker, what already ships, the build order for agents.

What was built around it

  • Measure. What you authorised and never asked for, Which agent is it?, Probes, not tables.
  • The bench. What is built, the simulator, experiments, the workbench.
  • Insurance for agents. The rating, before the money, the insurance book, and the push policy this repository still runs under.
  • Map your case. The assessment.
  • The books. A Key Means Nothing Alone.
  • The sources. Origins, February to August 2026, the documents, the dev packs.
pki.sgit.ai

A register of people and their public keys: verified by an anchor first, then by each other, with a link that only counts when it goes both ways; and the published work behind it.
