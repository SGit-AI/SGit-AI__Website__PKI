Grants · mandates · the gap nobody accepted

Map your own case

Pick the agents you run and the surface they run on, tick what you actually meant them to do, and see what the difference is. The output is a list of things somebody has to accept or decline — not a score, and not a report.

Everything here stays in this browser, and you can check that in ten seconds

This is a static site. There is no backend to send anything to, so the claim that we do not collect your assessment is architectural rather than operational — a property, not a promise. Open your browser's network panel, complete the whole thing, and watch: the only request this page makes is for library.json, and that is us sending you something.

And there is a second rule underneath that one, which matters more. A completed assessment describes which agents you run, on which machine, holding which credentials, with which containment, and which of those containments is only a setting. Individually those are unremarkable facts. Assembled, dated and ranked, they are a serviceable plan for attacking you — and we would have asked you to write it down.

So this page stores your choices, never your answers: identifiers from a public library, plus fixed options and dates derived from them.

There is no free-text box anywhere on this page. That is not an oversight and it is not a first version — it is the rule made checkable. You will notice it most where an acceptor should be a person's name: you pick a role instead, because a name is a fact about your organisation and this page has nowhere safe to put one. Scroll to the bottom and press the button to see the exact bytes held for you.

What browser storage actually gives you. Per browser, per device, per origin — it will not follow you to your phone. Cleared when you clear site data, and when a private window closes. No recovery of any kind. And readable by any script running on this origin, which is the reason for the references-only rule rather than an argument against storing anything. Losing this costs you almost nothing, by design: it is a handful of pointers into a public file.
The library has changed since you were last here. You were assessing against and this is . Your choices are unchanged. Anything that reads differently is the library moving, not you — which is why the version is recorded rather than assumed.

Your cases

A case is one agent installation on one surface. Most people have two or three, and they are not variants of each other: a local install is an enormous grant with a boundary you own and have not used, and a hosted one is a smaller grant with a boundary you cannot see. Neither wins.

What this is not

NotWhy it matters
Not a scannerNothing here inspects your machine. If a scan is ever added, its output belongs in your own vault and never in browser storage — which is an argument for building the vault path before the scan rather than after.
Not a scoreA number out of a hundred gets optimised for how alarming it feels. The measured finding is that a strong threat with a weak answer produces denial and reactance rather than change — worse than saying nothing, because it manufactures the counter-argument. So this shows a picture and an action, not a grade.
Not a durable recordBrowser storage has no recovery. When the vault path exists it will be offered rather than defaulted, because a vault swaps silent loss that costs little for a key with no reset.
Not a vendor assessmentThe library carries classes of installation, not named products, and every node says whether it was derived, taken from a published third-party tool, or measured. One hosted tree was measured — one vendor, one surface, one date, unnamed. Grading products would need measuring them.
Not an alarmEvery case ends on something you can actually do. Where the honest answer is that you can do nothing — the hosted containment — the page says so and gives you a request to make instead of a remedy to pretend at.

If it is wrong, that is the most useful thing you have

The trees are pre-computed claims about other people's products, dated, with the method published above each one so you can re-run it. A visitor saying that is not what my setup looks like is the cheapest correction this library will ever get. There is nowhere on this page to send that — deliberately, because a feedback box is a free-text box — so it goes to comms, or to the repository.
