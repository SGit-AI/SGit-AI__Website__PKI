The documents

The fifteen original markdown documents behind this site, captured verbatim under briefs/ and readable here. Each page carries the same apparatus — a summary, the key concepts linked to where they live on the site, the key ideas — and then the full document, rendered in-page from the raw markdown. The raw file stays the source of truth; the page is presentation. That raw-plus-curated split is the provenance discipline this project argues for, applied to itself.
