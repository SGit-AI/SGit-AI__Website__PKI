The documents

The twenty-one original markdown documents behind this site, captured verbatim under briefs/ and readable here. Each page carries the same apparatus — a summary, the key concepts linked to where they live on the site, the key ideas — and then the full document, rendered in-page from the raw markdown. The raw file stays the source of truth; the page is presentation. That raw-plus-curated split is the provenance discipline this project argues for, applied to itself.

pki.sgit.ai

A register of people and their public keys: verified by an anchor first, then by each other, with a link that only counts when it goes both ways; and the published work behind it. Part of the sgit.ai network — the vault layer and the shipped CLI this registry is designed onto. All content CC BY 4.0.
