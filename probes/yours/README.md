# yours/

Your mandate, your delta, your notes. **Everything in this folder except this file is gitignored**, and the root `.gitignore` says so. The failure mode of this whole design is somebody committing their mandate — a mandate is what one organisation expected of one agent, it belongs to them, and it is nobody else's business.

What flows back to the registry is a probe result, a profile correction, or an incident — each a fact about a vendor's product, never about you. Read `../templates/mandate-questionnaire.md` and answer it here.
