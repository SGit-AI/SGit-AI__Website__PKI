# The storyboard kit, vendored

`storyboard.js` and `storyboard.css` are `assets/storyboard.js` and `assets/storyboard.css` from
[gen-z-developers.sgit.ai](https://gen-z-developers.sgit.ai/storyboards/index.html)
([SGit-AI/SGit-AI__Website__Gen-Z-Developers](https://github.com/SGit-AI/SGit-AI__Website__Gen-Z-Developers), commit
`e2a71808f2dbdc9d94167b9493b539f0c567b35c`, 19 October 2026). `storyboard.css` is unchanged. `storyboard.js` has one
local patch, marked in the file: its `PROPS` merge `window.StoryboardExtraProps`, which `pki-props.js` defines, so this
site can draw keys, vaults and QR codes without editing the kit's own props. The unpatched file hashes to
`86212ff563e0bb0289abe2f6e2f405670087a0ef29b0cdd11c3d9adce36aaf67`.
`../vendor/rough-4.6.6.js` (Rough.js, MIT, its licence beside it) came from the same commit.

`pki-storyboards.css` maps the variables the kit's CSS reads onto this site's tokens. The pages are generated by
`admin/build/gen_storyboards.py` from `admin/content/storyboards/`.
