How to use this channel

  • Human → agent: reply in the working session, or edit this page / open an issue in the repo. Anything added under "Needed from the project lead" with an answer gets actioned next session.
  • Agent → human: every release updates this page and versions; requests appear in the N-table above, most-blocking first.
  • Decisions log: the site ships the pipeline before the content, so every release goes through a gate that already works; the PKI section was refactored across from nhi.sgit.ai rather than rewritten, so the two sites stay diffable; source briefs are captured verbatim under briefs/ with a curated page alongside, so the raw document and the presentation coexist; and the open questions are published unresolved rather than settled quietly.
